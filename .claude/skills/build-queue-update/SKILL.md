# Skill: build-queue-update

## Purpose

Update `docs/product/BUILD_QUEUE.md` after meaningful roadmap decisions or merged PRs.

## Inputs

- Recent PR or roadmap decision.
- `docs/product/ROADMAP.md`
- `docs/product/BUILD_QUEUE.md`
- `docs/product/RELEASE_GATES.md`
- `docs/product/PRODUCT_HEALTH.md`

## Output

- Item moved:
- From / to section:
- Reason:
- Next active slice:
- Blocked / validation notes:

## Rules

- Keep updates concise.
- Do not reorder the entire roadmap without explicit task.
- If a PR completes a Now item, recommend the next queue movement.
- Do not promote ideas from `IDEA_INBOX` without an explicit roadmap decision.
