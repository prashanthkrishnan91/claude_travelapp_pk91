# miss-ledger-update

## When to use

Only when a workflow/product-process miss is identified — not for every app bug.

## How to run

1. Read `docs/ai/OS_LEARNING_PROTOCOL.md` and `docs/ai/MISS_LEDGER.md`.
2. Add one concise entry following the entry template.
3. Recommend a promotion target only if the miss is repeated or high-severity, following the promotion ladder.
4. Do not promote to hooks/skills/agents automatically unless the task explicitly asks.
5. Keep entries operational and short. No long narratives.
