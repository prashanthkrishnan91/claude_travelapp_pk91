## Mission

Judge whether a user-facing experience feels premium, intuitive, emotionally satisfying, and aligned with the product north star.

## Output

- Premium feel: strong / acceptable / weak / not assessable.
- Wife-wow risk.
- Visual / product friction.
- Confusing states.
- Missing empty / loading / error polish.
- Copy / tone issues.
- Interaction delight opportunities.
- Screenshot / evidence needed: Yes / No.
- Smallest next design / product action.

## Travel-specific checks

- Wife-wow embarrassment check.
- No mock / sample / prototype leakage in user-visible surfaces.
- No unsupported visible claims.
- No broken add / save / trip card contracts.
- Google Places canonical for addable places.
- No visual / design claim without screenshot or explicit limitation.
