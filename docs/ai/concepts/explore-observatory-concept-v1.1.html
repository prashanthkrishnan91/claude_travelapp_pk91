The Observatory · A Direction Study

The browsing room next to the salon —
choose what you're looking for, then where.

Explore is the room beside the Concierge. It keeps the product's real shape: you pick what you want to browse first — Restaurants, Hotels, Attractions, or Flights — and each opens its own destination search. The Observatory dresses that flow in the Salon's materials: a wide meridian band sets the mood, the four verticals read as clear entry cards, and results arrive as verified editorial cards you can keep in your folio. Same house as the Salon, a calmer and more practical room.

Frame D

Mobile · Folio feedback

Saving fills the brass key and slips the place into the folio with one quiet line — the Salon's "kept in your folio" moment. Add-to-trip stays in Saved, never minted here.

Vertical-first, exactly like production

v1.1 corrects v1: there is no universal cross-vertical destination input. The landing room mirrors ExploreShell's four VerticalCards; tapping one calls the equivalent of setActive(vertical) and opens that vertical's own flow.

Each flow keeps its real inputs: Restaurants/Attractions take a destination; Hotels add dates/guests; Flights take origin + destination + dates. The desktop frame renders the correct fields per vertical.

Existing shell, existing actions

The header and mobile bottom nav are the current app shell (AppShell + AtelierNavArtifact + bottom nav) shown for context — production reskins inside them, no new navigation.

Result cards use the existing ResultActionSheet behaviour: Save writes to the folio; Map is the googleMapsUri link-out; Source reflects the TrustStrip. Add-to-trip is reached from Saved, never invented in Explore.

Mobile-first & honest

Landing fits one screen — short meridian + a 2×2 of named verticals (no clipped labels, ≥44px targets). Flow view collapses the banner and scrolls a scannable index; the active vertical + destination stay explicit via breadcrumb and banner.

Trust reads "Verified place · 1 source" only when the backend confirms it. Cards are photo-forward when a real source photo exists, with an honest typeset plate otherwise. No fabricated photos, ratings, awards, distances, or "open now" claims. Ambient drift + bloom are prefers-reduced-motion gated.
