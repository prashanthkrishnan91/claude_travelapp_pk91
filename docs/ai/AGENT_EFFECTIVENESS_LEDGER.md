# Agent Effectiveness Ledger — Travel

Track whether agents actually help or create noise.

## Template

```
## Agent effectiveness entry
Date:
Repo:
Agent:
PR/task:
Why used:
Useful output:
Miss caught:
False positives/noise:
Keep / tune / retire:
Follow-up:
```

## Rules

- Do not update for every tiny use.
- Update when an agent catches something important or creates repeated noise.
- Use this to prevent agent bloat.
- If an agent is repeatedly noisy, recommend retire or tune via `agent-curator`.
