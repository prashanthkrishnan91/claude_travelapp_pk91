# Idea Inbox

A safe parking lot for PK's ideas. Capture them here so they do not hijack active build slices.

Use `.claude/skills/idea-triage/SKILL.md` to classify new ideas. Promote to BUILD_QUEUE only via roadmap promotion.

## Idea template

```
- Idea:
- Repo:
- Product layer:
- Why it matters:
- Near / mid / long term:
- Dependencies:
- Risk:
- Decision: Now / Next / Later / Do Not Build Yet / Needs Research / Duplicate
- Follow-up trigger:
```
